# steitec/.github

Default community health files for all public repositories of
[steitec](https://github.com/steitec). GitHub uses them in every repository
that does not have its own version of the file.

| File | Purpose |
| ---- | ------- |
| [CODE_OF_CONDUCT.md](.github/CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [CONTRIBUTING.md](.github/CONTRIBUTING.md) | How to report issues and send pull requests |
| [SECURITY.md](.github/SECURITY.md) | How to report vulnerabilities privately |
| [ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE) | Bug report and feature request forms |
| [pull_request_template.md](.github/pull_request_template.md) | Pull request checklist |

## Brand assets

[brand/](brand) holds the steitec logo that the READMEs of all repositories
